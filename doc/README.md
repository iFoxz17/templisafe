# Documentation

This folder contains the project documentation beyond the short root
`README.md`.

## Documents

- [User guide](user-guide.md): public API, supported inputs, sources,
  configuration files and common workflows. Start here if you want to use the
  library.
- [Architecture](architecture.md): internal modules, abstractions, execution
  pipeline and extension points. Start here if you want to understand or
  contribute to the library.

## Diagram

The [architecture diagram](architecture.svg) is a draw.io export describing the
intended library architecture. The architecture document is the textual version
of that diagram and should be kept aligned with it.
