# SQLTemplater

## Installation

Follow these steps to set up the project locally:

1. **Clone the repository**  
```bash
   git clone <repo_url>
```

2. **Create a Python virtual environment**
```bash
   python -m venv .venv
```

3. **Activate the virtual environment**

**PowerShell:**
```powershell
   .\.venv\Scripts\Activate.ps1
```
   
**Bash:**
```bash
   source .venv/bin/activate
```

4. **Install the package and development dependencies, and run tests**
   
**PowerShell:**
```powershell
   .\setup_tests.ps1
```
   
**Bash:**
```bash
   ./setup_tests.sh
```

After running the setup script, the project is installed in editable mode and ready for development and testing.
